## Description

ValheimPictureFrame is a mod for Valheim.

Add a new piece of furniture, a picture frame.
You can decorate it with your favorite pictures.

## Install
https://www.nexusmods.com/valheim/mods/1124

---

Unofficial fork of [D-first/ValheimPictureFrame](https://github.com/D-first/ValheimPictureFrame)
([Nexus 1124](https://www.nexusmods.com/valheim/mods/1124)).

Original author: D-first. This tree retargets the 2021 mod to Valheim 1.0 / Unity 6
and adds a `shuffle` option for image folders. Not an official update.
